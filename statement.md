# Project Statement

## Problem Statement

Managing student academic information manually can be time-consuming and may lead to errors while maintaining student details, marks, and attendance records.

This project provides a Java-based Student Management System that allows users to manage student information, academic marks, and attendance through a command-line interface.

## Project Scope

The system focuses on basic academic record management for students. It provides functionality to add, view, search, update, and delete student information, manage marks, and maintain attendance records.

## Target Users

- Students
- Teachers
- Academic staff
- Educational institutions for basic student record management

## High-Level Features

### 1. Student Management

- Add student
- View students
- Search student
- Update student details
- Delete student

### 2. Marks Management

- Add marks for a student
- View marks
- Search marks
- Calculate total marks
- Calculate percentage
- Calculate grade

### 3. Attendance Management

- Add attendance record
- View attendance
- Search attendance
- Calculate attendance percentage
- Check attendance eligibility
